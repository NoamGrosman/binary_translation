Pin והיררכיית קוד

מונחהגדרה קצרהשימוש בפרויקט
PintoolPlugin ב־C/C++ שמשתמש ב־Intel Pin כדי לנתח או לשנות ביצוע של binary.project.so הוא Pintool.
IMGExecutable או shared library שנטענו לזיכרון.המתרגם בוחר את ה־main image.
SECSection ב־image, כגון .text, .plt, .init.מסננים sections רגישים ולא־בטוחים.
RTNRoutine/function כפי ש־Pin זיהה.יחידת probe replacement.
TRACEרצף דינמי בעל כניסה אחת וכמה יציאות ב־JIT.תרגילים 1–2 מכניסים instrumentation ברמת trace/BBL.
BBLBasic block: כניסה אחת ויציאה אחת.יחידת heat ו־layout.
INSInstruction אחת של x86.יחידת decode/encode ו־liveness.

תרגום וקוד

מונחהגדרה קצרהמשפט להגנה
Translation Cache (TC)אזור זיכרון executable שבו נשמר קוד מתורגם.“אנחנו בונים עותק ב־TC ומפנים אליו execution.”
TC1הגרסה הראשונה עם profiling.“TC1 לומד את ההתנהגות בפועל.”
TC2הגרסה השנייה שנבנית לפי profile.“TC2 משלם על build פעם אחת ומרוויח בשאר הריצה.”
IR / instr_mapרשומת metadata לכל instruction: מקור, יעד, bytes, גודל וקישורים.“זהו machine-level IR שמאפשר relocation ו־transformations.”
Chainingחיבור branch/call אל העותק המתורגם של target.“בלי chaining ה־TC היה חוזר שוב ושוב לקוד המקורי.”
Relocationתיקון כתובות יחסיות לאחר הזזת instruction.“אותו disp בכתובת חדשה אינו מצביע לאותו target.”
ProbeJump שנכתב בתחילת routine ומפנה replacement.“Probe mode מהיר אך מטיל עלינו אחריות ל־correctness.”
Wide NOPNOP רחב ששומר מקום ל־patch עתידי.“ה־NOP הוא patch site, לא padding מיותר.”

Profiling ואופטימיזציה

מונחהגדרה קצרהנוסחה/בדיקה
BBL heatמספר הפעמים שה־BBL בוצע.counter
Fall-throughהמשך לכתובת הסמוכה כאשר branch אינו נלקח.fallthru_counter
Taken heatכמה פעמים branch תנאי נלקח.counter - fallthru_counter
Indirect targetיעד שמחושב בזמן ריצה מ־register/memory.נאסף לפי address מלא.
De-virtualizationguard שמפנה target חם ל־direct branch ומשאיר indirect fallback.computed == hot ? direct : indirect
Livenessהאם value נוכחי ייקרא לפני overwrite.in = use ∪ (out − kill)
Dead registerRegister שהערך הנוכחי שלו כבר לא ייקרא.אפשר clobber ללא save/restore.
Code reorderingסידור BBLs כדי שהנתיב החם יהיה רציף/fall-through.לעיתים הופכים Jcc ומחליפים successors.
Gearingמעבר runtime ממצב profiling למצב optimized.TC1 → TC2 אחרי -prof_time.

נכונות ומדידה

Correctness

exit 0 + פלט byte-identical ל־native בכל run.

Verifier

כל direct/RIP target מגיע לכתובת המיועדת ול־instruction boundary.

Improvement

100*(base_median-opt_median)/base_median; היעד מעל 5%.
